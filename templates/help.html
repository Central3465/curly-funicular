Getting Started

Cypher is a substitution-cipher tool. You create a random 26-letter alphabet (the cipher), choose a secret key, and use both to encrypt and decrypt messages. Everything requires an account.

1. Create an account

  1. Open Register.
  2. Enter your full name, email address, and a password of at least 8 characters.
  3. Confirm the password and submit. Accounts are active immediately.

2. Log in

Go to Login and enter your email and password. Once you are logged in, the main page unlocks and the navigation bar shows your email, Help, Settings, and Logout.

Remember your password! Entering it wrong 5 times will lock you out! Currently, forgetting your password is a lost cause, so keep it somewhere safe.

Using the Web App

The main page has three tabs at the top: Encoder, Decoder, and Base Converter. Each shows a result box with a copy button when it has output. Success and error messages appear at the bottom of the card and disappear after a few seconds.

📝 Encoder: encrypt a message

  1. Under Setup Encoder, type a Secret Key. It cannot be blank.
  2. Get a cipher in one of two ways:
    • Click Generate Random Cipher, then Copy Cipher if you want to save it.
    • Or paste an existing cipher into Or Enter Existing Cipher. It must be a list of 26 different letters, such as ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"].
  3. Click Start Encoding. The cipher is checked on the server. If it is valid, the message form opens.
  4. Type your message and click Encode Message. Copy the result with Copy to Clipboard.
  5. Click Reset Setup to clear the cipher and key and start over.

🔍 Decoder: decrypt a message

  1. Under Setup Decoder, paste the same cipher that was used to encode the message.
  2. Enter the same secret key.
  3. Click Set Up Decoder, then paste the encrypted text into Encrypted Message and click Decode Message.
Setup lasts only while the page is open. Reloading the page clears your cipher and key, so keep a copy of both if you need them again.

🔢 Base Converter: numbers and text

The Base Converter has three modes, selected with the buttons at the top of the panel. Bases run from 2 to 36. Digits above 9 use the letters A–Z, and letter case is ignored on input.

  • Base Converter: enter a number, its From Base, and the To Base. For example, ff from base 16 to base 10 gives 255.
  • ASCII → Base: enter text and a target base. Each character becomes its own number, separated by spaces. For example, Hi in base 16 gives 48 69.
  • Base → ASCII: enter numbers separated by spaces and the base they are written in. Each number must be between 0 and 127. For example, 48 69 in base 16 gives Hi.

⚙️ Settings: account, usage, and API key

Open Settings from the navigation bar to see:

  • Your email, account creation date, tier, and status.
  • Your usage limits for the current 5-hour session and for the week, with reset times. See Usage limits.
  • The API Key section, where you can generate a key for the API. See Authentication.

How Ciphers Work

The cipher

A cipher is a shuffled alphabet of the 26 letters a–z. Every letter maps to exactly one other letter. For example, with the cipher above, a becomes q, b becomes w, and so on. Uppercase letters stay uppercase, and spaces, digits, and punctuation are copied through unchanged.

The secret key and decoy letters

The key decides where decoy letters are inserted. Roughly one position in four gets an extra random letter after it, and the positions are chosen from the key. The decoder skips those letters, so decoding gives back the original text only when you use the same cipher and key.

Plain messageKeyEncrypted output
hello worldmysecretitssgp vgksrz
Hi, Bob!key1Io,e vWgwv!

Both examples use the cipher ["q","w","e",…] from the API section, which maps a to q, b to w, and so on. Decoding either output with the same cipher and key returns the original message.

This is a classical cipher. It is fine for puzzles, learning, and light privacy, but it is not secure. Do not use it to protect passwords, personal data, or anything that matters.

Using the API

Every cipher and conversion feature in the web app is also available over HTTP. Requests and responses use JSON. For the full reference with the same examples, see the API Documentation page.

Authentication

There are two ways to authenticate:

  • API key (for scripts and other programs). Generate a key in Settings, then send it on every request: 
    X-API-Key: sk_your_api_key
  • Browser session. If you are logged in and calling from this site, your session cookie is enough.
Keep your key secret. The key is shown only once, right after you generate it, so copy it then. Generating a new key immediately invalidates the old one. Some endpoints accept only a browser session and reject API keys. The table below shows which.

Conventions

  • Send Content-Type: application/json on requests that have a body.
  • Most endpoints use POST. A few read-only endpoints use GET.
  • Successful responses return 200 or 201. Errors return a JSON object with an error message.
  • The cipher field can be a JSON array of 26 letters, or the same list written as a string such as "['q','w',…]".

Endpoints

Endpoints marked session or API key accept either. Endpoints marked session need a logged-in browser session and reject X-API-Key.

POST/api/generate-cipher

Returns a random shuffled alphabet. No body is needed.

curl -X POST https://curly-funicular-production.up.railway.app/api/generate-cipher \
  -H "X-API-Key: sk_your_api_key"
{
  "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"],
  "success": true
}

POST/api/validate-cipher

Body: cipher. Returns 200 either way, with valid set to true or false.

curl -X POST https://curly-funicular-production.up.railway.app/api/validate-cipher \
  -H "X-API-Key: sk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"]}'
{
  "valid": true,
  "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"]
}

POST/api/encode

Body: cipher, message, and key. The key cannot be empty.

curl -X POST https://curly-funicular-production.up.railway.app/api/encode \
  -H "X-API-Key: sk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"],
    "message": "hello world",
    "key": "mysecret"
  }'
{
  "encrypted": "itssgp vgksrz"
}

POST/api/decode

Body: cipher, message (the encrypted text), and key. Use the same cipher and key that were used to encode.

curl -X POST https://curly-funicular-production.up.railway.app/api/decode \
  -H "X-API-Key: sk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"],
    "message": "itssgp vgksrz",
    "key": "mysecret"
  }'
{
  "decoded": "hello world"
}

POST/api/convert-base

Session only. Body: number (a string), from_base, and to_base. Both bases must be from 2 to 36.

curl -X POST https://curly-funicular-production.up.railway.app/api/convert-base \
  -H "Cookie: session=your_session_cookie" \
  -H "Content-Type: application/json" \
  -d '{"number": "ff", "from_base": 16, "to_base": 10}'
{
  "result": "255",
  "success": true
}

POST/api/ascii-to-base

Session only. Body: text and base (2 to 36). The result is each character's code converted to that base, separated by spaces.

{"text": "Hi", "base": 16}
{
  "result": "48 69",
  "success": true
}

POST/api/base-to-ascii

Session only. Body: numbers (space-separated, in the given base) and base. Each value must be between 0 and 127.

{"numbers": "48 69", "base": 16}
{
  "result": "Hi",
  "success": true
}

GET/api/usage-limits

Session only. Returns your current counts, maximums, and reset times.

{
  "session_limit": {"current": 3, "max": 50, "percentage": 6, "reset_at": "2026-10-10T18:00:00"},
  "weekly_limit":  {"current": 41, "max": 250, "percentage": 16, "reset_at": "2026-10-16T13:00:00"}
}

POST/api/generate-api-key

Session only. Creates a new key and invalidates any previous one. The response includes the key once. Requests from a browser session also need an X-CSRFToken header. Get a token from GET /api/csrf-token.

{
  "success": true,
  "api_key": "sk_..."
}

Usage limits

Every successful cipher or conversion request counts toward two limits, whichever way you authenticate: a session limit that resets 5 hours after it starts, and a weekly limit that resets 7 days after it starts. Requests that fail do not count. Your tier sets the maximums:

Your current tier and usage are shown in Settings. Note that /api/validate-cipher returns 200 even when the cipher is invalid, so that call still counts.

Example: round trip in Python

This script generates a cipher, encodes a message, and decodes it again. It uses the requests package.

import requests

BASE = "https://curly-funicular-production.up.railway.app"
HEADERS = {"X-API-Key": "sk_your_api_key", "Content-Type": "application/json"}
KEY = "mysecret"

cipher = requests.post(f"{BASE}/api/generate-cipher", headers=HEADERS).json()["cipher"]

encoded = requests.post(f"{BASE}/api/encode", headers=HEADERS, json={
    "cipher": cipher, "message": "hello world", "key": KEY,
}).json()["encrypted"]

decoded = requests.post(f"{BASE}/api/decode", headers=HEADERS, json={
    "cipher": cipher, "message": encoded, "key": KEY,
}).json()["decoded"]

print(encoded, "->", decoded)

In real code, check response.ok before reading the JSON, so a 401 or 429 does not cause a confusing KeyError.

Troubleshooting

"Session expired. Please reload…" or actions stop working

Your login session has ended. Reload the page and log in again.

"Session limit reached" or "Weekly limit reached"

You have used your allowance for the current window. The message shows when it resets. You can check your usage in Settings.

"Invalid email or password" and then a block

Check your email and password. After 5 failed attempts from the same IP address, logins from that address are blocked for 24 hours. Wait for the countdown to finish, or try again from a different network.

"Your account has been restricted" or "This account has been banned"

An administrator has restricted this account. Contact the site administrator if you think this is a mistake.

"Cipher must contain exactly 26 letters" or "All letters must be unique"

A cipher needs all 26 letters a–z, each used exactly once. Use Generate Random Cipher if you are not sure how to write one.

Decoding gives garbage

Check that you used the exact same cipher and key that were used to encode. Any change to either, including an extra space or a different letter case in the key, produces different output.

"Invalid number for base N"

The number contains a digit that is not allowed in that base. For example, G is not valid in base 16. Check the number and its base.
