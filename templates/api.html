📄 Cipher API Documentation

← Back to App ⚙️ Settings

These endpoints let you run the substitution-cipher tools programmatically instead of through the web UI.

Authenticate every request with either your browser session (if you're logged in and calling from this site) or an API key. For external callers, generate a key in Settings and send it on every request as:

X-API-Key: <your_key>

Requests with no valid session and no valid X-API-Key header are rejected with 401 Unauthorized. All endpoints are POST, accept a JSON body, and count against your account's usage limits (visible in Settings) regardless of which auth method you use.

POST /api/generate-cipher
Generates a random 26-letter substitution cipher (a shuffled alphabet).

Parameters

None.

Example request

curl -X POST https://curly-funicular-production.up.railway.app/api/generate-cipher \
  -H "X-API-Key: sk_your_api_key"

Example response 200

{
  "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"],
  "success": true
}

Possible errors

Status Response
401 {"error": "Unauthorized. Please log in or provide a valid API key in the X-API-Key header."}
429 {"error": "Session limit reached. Resets in Xh Ym"}
500 {"error": "<message>"}
POST /api/validate-cipher
Checks that a 26-letter cipher is well-formed (every letter of the alphabet appears exactly once).

Parameters

Name Type Required Description
cipher array[string] (or its string form) Yes 26-letter substitution cipher to validate.

Example request

curl -X POST https://curly-funicular-production.up.railway.app/api/validate-cipher \
  -H "X-API-Key: sk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"]}'

Example response 200 (valid)

{
  "valid": true,
  "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"]
}

Example response 200 (invalid)

{
  "valid": false,
  "error": "Cipher must contain exactly 26 letters"
}

Possible errors

Status Response
401 {"error": "Unauthorized. Please log in or provide a valid API key in the X-API-Key header."}
429 {"error": "Weekly limit reached. Resets in Xd Yh Zm"}
POST /api/encode
Encrypts a plaintext message using a substitution cipher and a secret key.

Parameters

Name Type Required Description
cipher array[string] Yes 26-letter substitution cipher, e.g. from /api/generate-cipher.
message string Yes Plaintext message to encrypt.
key string Yes Secret key used to derive decoy characters; cannot be empty.

Example request

curl -X POST https://curly-funicular-production.up.railway.app/api/encode \
  -H "X-API-Key: sk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"],
    "message": "hello world",
    "key": "mysecret"
  }'

Example response 200

{
  "encrypted": "itssg vgksr"
}

Possible errors

Status Response
400 {"error": "Key cannot be empty"}
400 {"error": "<cipher validation error>"}
401 {"error": "Unauthorized. Please log in or provide a valid API key in the X-API-Key header."}
429 {"error": "Session limit reached. Resets in Xh Ym"}
500 {"error": "<message>"}
POST /api/decode
Decrypts a message that was encoded with /api/encode using the matching cipher and key.

Parameters

Name Type Required Description
cipher array[string] Yes The same 26-letter substitution cipher used to encode the message.
message string Yes Encrypted message to decrypt.
key string Yes Secret key that was used to encode the message; cannot be empty.

Example request

curl -X POST https://curly-funicular-production.up.railway.app/api/decode \
  -H "X-API-Key: sk_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "cipher": ["q","w","e","r","t","y","u","i","o","p","a","s","d","f","g","h","j","k","l","z","x","c","v","b","n","m"],
    "message": "itssg vgksr",
    "key": "mysecret"
  }'

Example response 200

{
  "decoded": "hello world"
}

Possible errors

Status Response
400 {"error": "Key cannot be empty"}
400 {"error": "<cipher validation error>"}
401 {"error": "Unauthorized. Please log in or provide a valid API key in the X-API-Key header."}
429 {"error": "Session limit reached. Resets in Xh Ym"}
500 {"error": "<message>"}
